# 🎄 HackMas: Catch some Christmas Zen

**Level up your productivity while the snow falls.**
HackMas is a gamified study companion that turns your holiday study sessions into an festive RPG adventure.

---

## 📖 The Vision
The holidays are filled with distractions—cocoa, family, and the constant urge to check the mailbox. HackMas helps you stay on track by gamifying the Pomodoro technique. Every focus session earns you XP, every task completed brings you closer to festive glory, and your hard work unlocks the ultimate holiday soundtrack.

## ✨ Festive Features

### 🍅 Holiday Focus Timer
Not just a clock. It's a journey. Start a festive focus session, stay off your phone, and earn **XP** for every minute of deep work.

### 📝 Quest Log (Tasks)
Turn your "To-Do" list into a "Quest Log". Hear that satisfying **"Ding!"** and watch the confetti fly as you clear your holiday backlog.

### 🎁 The Gift Shop
Hard-earned XP deserves better than just a number. Visit the shop to spend your points on exclusive holiday-themed badges and profile flair.

### 📻 Silent Night Radio
Progress through your levels to unlock exclusive **Lo-Fi festive tracks**. From "Silent Night Lo-Fi" to "Deck the Halls (Chillhop Remix)", your focus has never sounded this cozy.

### 📊 Bragging Rights (Social Share)
Generate a beautiful, personalized **Share Card** of your stats. Show off your streak and your level to your study group or on social media.

### 🛡️ North Pole Security
We play fair here. Daily XP caps ensure everyone stays productive without burning out before New Year's Eve.

## 🚀 Get Started

### 1. Requirements
*   Node.js (v18+)
*   Python (v3.9+)

### 2. Frontend Setup
```bash
npm install
npm run dev
```
Visit: `http://localhost:3000`

### 3. Backend Setup
```bash
cd backend
pip install -r requirements.txt
python app.py
```
API runs on: `http://127.0.0.1:5555`
