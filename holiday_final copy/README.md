# 🎄 HackMas: Holiday Study Buddy

**Track:** Productivity
**Theme:** Holiday Season

## 📖 About
HackMas is a gamified productivity app designed to help students stay focused during the holiday season. It combines the Pomodoro technique with RPG elements, allowing users to earn XP, level up, and unlock festive rewards by completing tasks and focus sessions.

## ✨ Features
*   **🍅 Holiday Focus Timer:** A Pomodoro timer with a festive twist. Earn XP for every minute of focus.
*   **📝 Gamified Tasks:** Create tasks and get rewarded with "Ding" sounds and confetti upon completion.
*   **🎁 Gift Shop:** Spend your hard-earned XP to unlock holiday-themed badges and rewards.
*   **📻 Holiday Radio:** Unlock exclusive Lo-Fi holiday tracks (like "Silent Night Lo-Fi") by progressing through the game.
*   **📊 Social Sharing:** Generate a beautiful "Share Card" of your stats to show off your streak.
*   **🛡️ Anti-Cheat:** Fair play is ensured with daily XP caps.

## 🛠️ Tech Stack
*   **Frontend:** Next.js, Tailwind CSS, Shadcn UI, Framer Motion
*   **Backend:** Flask, SQLAlchemy, SQLite
*   **Tools:** `html-to-image` for social sharing, `js-confetti` for effects.

## 🚀 Getting Started

### Frontend
1.  `npm install`
2.  `npm run dev`
3.  Open [http://localhost:3000](http://localhost:3000)

### Backend
1.  `cd backend`
2.  `pip install -r requirements.txt`
3.  `python app.py`
4.  Server runs on [http://127.0.0.1:5555](http://127.0.0.1:5555)

## 🎅 Why it matters
The holidays are a time of distraction. HackMas turns studying into a game, making productivity feel like opening a present.
